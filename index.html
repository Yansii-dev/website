What it is

Plainly, what YANSII does

YANSII is a Chrome extension for testing the security of web applications. The free tier is a passive scanner — it runs 46 checks as you browse and shows findings as either a potential indicator (a pattern worth a manual look) or an observed fact (something directly verifiable, like a missing header). It doesn't exploit anything or claim a vulnerability is confirmed unless there's evidence for it. Think of it as a second pair of eyes on the page you're already looking at — not an autonomous scanner making decisions for you.

How findings are shown

A finding is labeled by how sure we are — not inflated to look scarier

A finding is only as useful as your trust in it. YANSII separates what's possible from what's observed from what's confirmed, so you know how much weight to give each line before you spend time on it.

POTENTIAL

Pattern-based indicator

A passive check matched something that's often worth investigating — shown in grey, collapsed by default, never given a severity color until it's verified.

OBSERVED

Directly verifiable fact

Something the page itself confirms with no interpretation needed — a missing security header, an insecure cookie flag, an exposed endpoint.

CONFIRMEDPRO

Evidence-backed finding

Active validation captures proof — a response diff showing another party's data, for example. Only confirmed findings get a real severity rating.

Manual install — about 2 minutes

  1. Download yansii-v2.2.0-free.zip from the latest GitHub release (147 KB)
  2. Unzip it to a folder
  3. Open chrome://extensions and enable Developer mode (toggle, top right)
  4. Click Load unpacked and select the unzipped folder
  5. Pin YANSII to your toolbar — it's ready

FAQ

Common questions

+Is it really free?

Yes. The passive scanner — 46 checks, dashboard, crawler, exports — is free and open source, forever. It's not a limited trial of something else.

+Does it send my data anywhere?

No. The free tier runs entirely in your browser — nothing is sent externally. When Pro's AI features launch, they'll send limited page context (endpoint URLs, parameter names, detected technology — never cookies, tokens, credentials, or full response bodies) to whichever AI provider you connect, using your own API key. See the privacy policy for details.

+What's the difference between free and Pro?

Free is a passive scanner — it shows potential indicators and observed facts. Pro adds active validation (which promotes findings to confirmed with evidence), an AI copilot, request replay, and several more testing tools.

+When does Pro launch?

Soon — we're not committing to an exact date. It will ship with a 14-day free trial, full access, no credit card required to start.

+Do AI features cost extra?

AI features use your own API key (bring your own key) with Anthropic, OpenAI, Groq, or OpenRouter — you pay them directly for usage. YANSII doesn't add a markup; the only YANSII charge is the Pro subscription itself. Typical API cost is $5–15/month. All 46 free-tier scanners work without any API key.

+Do I need an account?

No account for the free extension. Pro will require a license key tied to your subscription, activated locally.

+Is it open source?

The free tier is fully open source on GitHub, licensed under BSL 1.1. It collects zero telemetry — you can verify that directly in the source.

+Is it safe to use?

Use it only on applications you own or are explicitly authorized to test. YANSII is a testing aid, not a license to test anything you like — that responsibility stays with you.
