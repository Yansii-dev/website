Claude Code Bridge

Connect YANSII to Claude Code CLI. Pull live findings, traffic, endpoints, and cookies into your terminal. Replay requests, trigger scans, set scope — all from the command line.

AI features (Copilot, Deep Dive, Verify) use your API key in the extension. The bridge handles data sync — they work independently.

Overview

What the bridge does

The bridge connects YANSII's live browser data to Claude Code via MCP (Model Context Protocol). Claude Code gets direct access to everything the extension captures — so you can analyze, script, and automate from your terminal instead of clicking through the popup.

Available MCP tools

ToolWhat it does
yansii_get_findingsPull all findings with severity, evidence, and status
yansii_get_trafficGet captured HTTP requests and responses
yansii_get_endpointsList all discovered endpoints and parameters
yansii_get_cookiesRead cookie attributes and security flags
yansii_get_localstorageAccess localStorage/sessionStorage data
yansii_get_domGet live DOM snapshots from the active tab
yansii_replay_requestReplay a captured request with modified headers or body
yansii_trigger_scanStart a passive scan from the terminal
yansii_set_scopeConfigure target scope without opening the popup
yansii_add_findingAdd a manual finding from Claude Code

What this means in practice

Instead of switching between the extension popup and your terminal, you stay in Claude Code:

"Show me all high-severity findings from this session" pulls via MCP
"Replay this request without the auth header" sends replay, compares
"What cookies on this domain are missing Secure flag?" reads live cookie data
"Write a report of everything found so far" pulls findings, writes markdown

Setup

Get connected

Requirements: YANSII Pro subscription · Claude Code CLI · Node.js 18+

1

Install the bridge

git clone https://github.com/Yansii-dev/yansii-bridge.git
cd yansii-bridge
npm install
2

Add to Claude Code MCP config

Add this to your Claude Code MCP settings (~/.config/claude/mcp.json or via claude mcp add):

{
  "mcpServers": {
    "yansii": {
      "command": "node",
      "args": ["/path/to/yansii-bridge/bridge.js"]
    }
  }
}

Replace /path/to/yansii-bridge/ with the actual path where you cloned the repo. Find it by running pwd inside the yansii-bridge folder.

3

Connect from the extension

Open YANSII → scroll to the Claude Code Bridge section (visible with a Pro license) → toggle to Connected. The status indicator shows the WebSocket connection state.

4

Verify in Claude Code

Ask Claude Code:

"Use yansii_get_findings to show my current scan results"

If findings come back, the bridge is working.

Best practice

Recommended setup

API key — for AI features

Set an Anthropic or Groq key in the extension popup. This powers Copilot, Deep Dive, and AI Verify. Runs entirely in the extension.

Bridge — for data sync

Connect the bridge for Claude Code access to live scan data. Analyze findings in bulk, generate reports, script replay sequences, build automation.

Both work simultaneously. The extension uses your API key for AI and the bridge for data sync — they don't compete.
