2. The Service

YANSII is a Chrome browser extension for AI-assisted security testing. It passively scans web pages you visit for potential vulnerabilities, captures traffic data, and provides an AI copilot to suggest what to test next.

YANSII is available in two tiers:

  • Free — 46 passive scanners, dashboard, crawler, exports. No cost, no account required.
  • Pro — All Free features plus AI Copilot, agentic memory, request replay, role comparison, parameter discovery, GraphQL scanning, report builder, and other advanced features. Requires a paid subscription.
YANSII is a testing assistant, not a guarantee of security. It does not replace professional penetration testing, code review, or security audits.

6. Data Handling

YANSII stores all scan findings, settings, memory patterns, and captured traffic locally on your device using chrome.storage.local. No finding data, browsing history, or captured traffic is sent to YANSII servers.

When you use AI features (Copilot, Deep Analysis), page context data is sent directly from your browser to your chosen AI provider using your own API key. This data is used solely for generating security testing suggestions and is subject to your AI provider's terms and privacy policy.

The only data sent to YANSII infrastructure is license key validation requests to the Cloudflare Worker at api.yansii.in. These requests contain your license key and a device fingerprint. License keys are redacted in server logs.

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
